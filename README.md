A **Java Console-Based Library Management System** developed using **Object-Oriented Programming (OOP)**, **Collections Framework**, and **File Handling**. The application enables efficient management of books, members, book issue/return operations, and persistent data storage.

# 📖 Features

### 📚 Book Management

- ➕ Add New Book
- 📋 View All Books
- 🔍 Search Book by ID
- ✏️ Update Book Details
- ❌ Delete Book

---

### 👨‍🎓 Member Management

- ➕ Add Member
- 👀 View Members
- 🔍 Search Member

---

### 📖 Book Transactions

- 📕 Issue Book
- 📗 Return Book
- ✅ Availability Tracking

---

### 💾 Data Persistence

- Save Books using File Handling
- Save Members using File Handling
- Automatically Load Previous Data

---

### 📊 Statistics

- Total Books
- Total Members
- Available Books
- Issued Books

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/nikita-bharti18/Library_Management_Java.git
```

---

## Navigate to Project

```bash
cd Library_Management_Java
```

---

## Compile

```bash
javac src/*.java
```

---

## Run

```bash
java -cp src Main
```
